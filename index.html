Methodology and interpretation

Online building inventory: retrieves building objects tagged in OpenStreetMap. Completeness varies by location and contributor activity.

Administrative analysis: uses downloaded boundary geometries where available.

Detection analysis: imported model output is analysed by class and confidence. A greenhouse label is only reported when it exists in the imported data.

EW-YOLOv8 context: the referenced research combines DySample, Normalized Wasserstein Distance (NWD) and Slide classification weighting. This HTML dashboard does not implement or reproduce the model.

Online data sources

• OpenStreetMap — mapped buildings and roads.
• Overpass API — OpenStreetMap feature queries.
• geoBoundaries — administrative boundary data.
• Esri World Imagery — satellite basemap.
• ESA WorldCover — land-cover reference.
• Google Open Buildings — separate building-footprint dataset; not queried directly by this browser application.
• Overture Maps — additional global mapping data.
